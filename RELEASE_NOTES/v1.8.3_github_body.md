# Version 1.8.3 — Anima Q/K RMSNorm + split-half RoPE fuse

This release speeds up **Anima** Self-Attention by fusing **Q/K RMSNorm** and **split-half RoPE** into a single `comfy-kitchen` kernel (`rms_rope_split_half`), applied through Forge-only glue. Vendored `ComfyUI-master/` sources are not edited.

It also tightens **FA-2 / SA2 / SA3** console logging so “kernel ran” messages appear only after a real kernel return.

---

## 1. Summary

| Item | Detail |
|---|---|
| Primary feature | Anima SelfAttn + RoPE → `comfy_kitchen.rms_rope_split_half` |
| Dependency | **`comfy-kitchen>=0.2.21`** (root `requirements.txt`) |
| Install path | Anima UNet load in `backend/loader.py` → `install_anima_rms_rope_fuse()` |
| Patch target | `comfy.ldm.cosmos.predict2.Attention.compute_qkv` (class method, once) |
| Unchanged | Attention UI (Default / FA-2 / SA2 / SA3), CrossAttn, no-rope SelfAttn, Krea2, llm_adapter Attention |
| Secondary | FA-2 / SA2 / SA3 log only after real kernel return (`backend/attention_backend_info.py`) |

**Expected effect:** fewer separate CUDA kernels between Q/K RMSNorm and split-half RoPE on Anima SelfAttn + rope.

---

## 2. Why Forge glue (not ComfyUI-master)

Anima DiT runs through Comfy `comfy.ldm.anima.model.Anima` → `MiniTrainDIT` → `comfy.ldm.cosmos.predict2.Attention`. There is no in-tree Anima `Attention` to edit, and this fork must **not** modify `ComfyUI-master/`.

Implementation lives only in Forge glue:

1. **`backend/nn/comfy_anima.py`** — `install_anima_rms_rope_fuse()` + patched `compute_qkv`
2. **`backend/loader.py`** — call install once on the Anima load branch (with `remap_anima_state_dict`)
3. **`requirements.txt`** — pin `comfy-kitchen>=0.2.21`

---

## 3. Patched `compute_qkv` behavior

After Q/K/V projection and head rearrange:

```text
if self.is_selfattn and rope_emb is not None:
    q_scale = self.q_norm.weight.to(dtype=q.dtype, device=q.device)
    k_scale = self.k_norm.weight.to(dtype=k.dtype, device=k.device)
    eps = float(getattr(self.q_norm, "eps", 1e-6))
    q, k = quant_ops.ck.rms_rope_split_half(q, k, rope_emb, q_scale, k_scale, eps)
else:
    q = self.q_norm(q)
    k = self.k_norm(k)

v = self.v_norm(v)
return q, k, v
```

### 3.1 Scale cast (plan B)

Anima uses Comfy `operations.RMSNorm` (no Forge `weights_manual_cast` stream). Scales are taken from `q_norm.weight` / `k_norm.weight` and cast to the activation dtype/device before the fused call.

### 3.2 Attribute name

Comfy `Attention` uses **`is_selfattn`** (not classic `is_SelfAttn`).

## 4. Install rules and console messages

| Condition | Behavior |
|---|---|
| First successful install | Replaces `Attention.compute_qkv`; prints success line (and logs) |
| Already installed / already marked | No-op; returns True |
| `rms_rope_split_half` missing | Keeps stock `compute_qkv`; prints warning once |
| Exception during install | Keeps stock path; prints failure once |

**Success line (visible in Forge console):**

```text
[Anima] Installed rms_rope_split_half fuse on comfy.ldm.cosmos.predict2.Attention.compute_qkv (SelfAttn+rope only; CrossAttn unchanged).
```

Messages use **`print` + logging** (same pattern as FA-2 / `attention_backend_info`) so they appear in the WebUI console, not only in a logger namespace.

Timing: printed during Anima UNet load, after state-dict key summary and before `K-Model Created`.

## 5. Scope and side effects

### 5.1 Intended

- Anima DiT SelfAttn with `rope_emb` → fused kernel
- CrossAttn / SelfAttn without rope → stock `q_norm` / `k_norm`
- `v_norm` always stock
- Attention backend selection unchanged (use **Default** or **FA-2** for Anima; SA2/SA3 remain non-recommended for Anima image quality)

### 5.2 Shared-class side effect (documented)

Install replaces the **class method** on `comfy.ldm.cosmos.predict2.Attention`. Any other loader that uses the same class (e.g. Cosmos Predict2 MiniTrainDIT) would see the patched method after Anima has been loaded once in the process.

Mitigation already in the patch:

1. Fuse branch is **SelfAttn + rope only**
2. Install is invoked only from the **Anima loader branch**

## 6. Dependency upgrade

Root `requirements.txt`:

```text
comfy-kitchen>=0.2.21
```

If an older kitchen is installed, Anima still loads with the stock path and a one-time console warning. Upgrade the venv package to get the fuse.

Use this fork’s `venv` (the one `webui.bat` activates), not an unrelated environment.

## 7. Secondary: FA-2 / SA2 / SA3 “kernel ran” logging

Commit **`eda1d8f`** (`backend/attention_backend_info.py`):

- Console lines such as `[Forge] FA-2 kernel ran ...` (and SA2/SA3 equivalents) are emitted only **after the real kernel returns**, not merely because a dispatcher path was selected.
- Reduces false positives when switching Attention UI or when a backend is installed but not actually invoked for that sample.

This is independent of the Anima fuse; it applies to the shared Attention dispatcher for all models.

## 9. Verification checklist

1. Load an Anima UNet (e.g. `waiANIMA_*.safetensors`) with Qwen-Image VAE + TE modules as usual.
2. Confirm console shows the **`[Anima] Installed rms_rope_split_half fuse ...`** line at load time.
3. Generate with Attention **FA-2** or **Default**; confirm sampling completes and (for FA-2) `[Forge] FA-2 kernel ran ...` after a real call.
