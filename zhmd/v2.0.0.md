# 版本 2.0.0 — Python 3.14 专属运行环境与多平台全面兼容性更新

本次重大发布将 Forge 运行环境全面升级并仅支持 **Python 3.14**（覆盖 Windows 与 Linux，基于 CUDA 13.2 / PyTorch 2.13 架构），内置自动化 Universal Wheel 分发、原生 Linux 及 Windows Nunchaku 1.3.0 预编译 Wheel、SageAttention 3（SA3 / Blackwell FP4）后端支持以及全面的运行时兼容性修复。

---

## 1. 概述

| 项目 | 详情 |
|---|---|
| 运行环境目标 | **仅支持 Python 3.14**（CUDA 13.2 / PyTorch 2.13 架构），覆盖 Windows 与 Linux |
| Universal Wheel | 自动化安装 `distutils`、`pyaudioop`、`imghdr`、`facexlib` 与 `gradio 4.40.0` |
| Nunchaku 1.3.0 | 提供适用于 Python 3.14 的 **Windows** (`win_amd64`) 与 **Linux** (`linux_x86_64`) 预编译 Wheel |
| Attention 后端 | 支持在 **Default** (SDPA)、**SA2** (SageAttention 2)、**SA3** (SageAttention 3 / Blackwell FP4) 与 **FA2** (FlashAttention 2) 之间运行时快速切换 |
| 音频库兼容 | 内置 `torchaudio_compat` 模块，提供符合标准的 ModuleSpec Stub，解决 Python 3.14 导入异常 |
| 架构与状态修复 | 修复 `StableDiffusionProcessing.sd_model` 属性同步机制，消除 `modules/shared.py` 模块变量遮蔽 |
| 内存管理持久化 | 修复 `config.json` 对 `CUDA Stream` (`Async`) 与 `Pinned Memory` (`Shared`) 的持久化配置 |

---

## 2. 核心改动与技术细节

### 2.1 Python 3.14 Universal Wheel 分发体系
针对 Python 3.14 环境移除的旧版标准库与版本约束，构建并内置了 Universal Wheel 自动下载与安装机制：
- **`distutils`**：绑定定制版 Universal Wheel（`distutils-3.14.0-py3-none-any.whl`）。
- **`pyaudioop`** 与 **`imghdr`**：绑定针对 Python 3.13/3.14 移除模块的纯 Python 替代 Wheel。
- **`facexlib`**：构建纯 Python Universal Wheel（`facexlib-0.3.0-py3-none-any.whl`），彻底剥离 `numba` 与 `filterpy` 强依赖绑定，内置 `version.py` 并为 `@jit` 函数提供安全回退。
- **`gradio 4.40.0`**：绑定解除依赖锁定的定制版 Wheel，并在 `modules_forge/transformers_cache_compat.py` 中适配 OpenAPI 布尔 schema 转换。

### 2.2 Nunchaku 1.3.0 预编译 Wheel（Windows & Linux）
集成基于 CUDA 13.2 / Python 3.14 编译的二进制 Wheel：
- **Windows**：`https://huggingface.co/ussoewwin/nunchaku-built-on-cu132/resolve/main/nunchaku-1.3.0.dev20260619%2Bcu13.2torch2.12-cp314-cp314-win_amd64.whl`
- **Linux**：`https://huggingface.co/ussoewwin/nunchaku-built-on-cu132/resolve/main/nunchaku-1.3.0.dev20260829%2Bcu13.2torch2.13-cp314-cp314-linux_x86_64.whl`

### 2.3 SageAttention 3 (SA3 / Blackwell FP4) 与 Attention 后端
- 新增 `sageattn3` 自动安装支持（`sageattn3-1.0.0+cu132torch2.13.0-cp314-cp314-win_amd64.whl`）。
- Quicksettings 中原生支持 **`Default`**、**`SA2`**、**`SA3`** 与 **`FA2`** 无缝切换。

### 2.4 Torchaudio 兼容性与 SD 模型属性同步
- 新增 `modules_forge/torchaudio_compat.py`，注册合法的 `importlib.machinery.ModuleSpec`，无需编译安装二进制 torchaudio 即可满足 transformers/diffusers 的环境检测。
- 移除 `modules/shared.py` 中的静态 `sd_model = None`，防止遮蔽 `Shared` 模块类上的动态描述符属性。
- 将 `StableDiffusionProcessing.sd_model` 设为 `init=False` dataclass 字段，避免实例构造时被误重置为 `None`。

## 3. 安装与更新说明

1. 拉取最新仓库更新：
   ```bash
   git pull
   ```
2. 确认 Python 版本为 **Python 3.14**：
   ```bash
   python --version
   ```
3. 运行 `webui-user.bat`（Windows）或 `webui.sh`（Linux）。首次启动时将自动检测并安装所有必要的 Universal Wheel 与依赖包。
