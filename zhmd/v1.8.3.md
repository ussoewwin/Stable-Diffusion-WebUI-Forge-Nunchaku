# Version 1.8.3 — Anima Q/K RMSNorm + split-half RoPE 融合

本版本通过 Forge 专用糊代码，将 **Q/K RMSNorm** 与 **split-half RoPE** 融合为单个 `comfy-kitchen` 内核（`rms_rope_split_half`），以加速 **Anima** Self-Attention。供应商目录 `ComfyUI-master/` **不会**被修改。

同时收紧 **FA-2 / SA2 / SA3** 控制台日志：仅在真实内核返回之后才打印 “kernel ran” 类消息。

---

## 1. 概述

| 项目 | 详情 |
|---|---|
| 主要功能 | Anima SelfAttn + RoPE → `comfy_kitchen.rms_rope_split_half` |
| 依赖 | **`comfy-kitchen>=0.2.21`**（仓库根目录 `requirements.txt`） |
| 安装路径 | `backend/loader.py` 的 Anima UNet 加载分支 → `install_anima_rms_rope_fuse()` |
| 补丁目标 | `comfy.ldm.cosmos.predict2.Attention.compute_qkv`（类方法，仅一次） |
| 不变 | Attention UI（Default / FA-2 / SA2 / SA3）、CrossAttn、无 RoPE 的 SelfAttn、Krea2、llm_adapter 用 Attention |
| 次要 | FA-2 / SA2 / SA3 仅在真实内核返回后打日志（`backend/attention_backend_info.py`） |

**预期效果：** 减少 Anima SelfAttn + rope 上 Q/K RMSNorm 与 split-half RoPE 之间的分离 CUDA 内核往返。

---

## 2. 为何用 Forge 糊（而非 ComfyUI-master）

Anima DiT 经 Comfy `comfy.ldm.anima.model.Anima` → `MiniTrainDIT` → `comfy.ldm.cosmos.predict2.Attention` 运行。仓库内没有可直接编辑的 Anima `Attention`，且本 fork **不得**修改 `ComfyUI-master/`。

实现仅存在于 Forge 糊：

1. **`backend/nn/comfy_anima.py`** — `install_anima_rms_rope_fuse()` + 补丁版 `compute_qkv`
2. **`backend/loader.py`** — 在 Anima 加载分支（与 `remap_anima_state_dict` 同行）调用一次 install
3. **`requirements.txt`** — 固定 `comfy-kitchen>=0.2.21`

---

## 3. 补丁后的 `compute_qkv` 行为

在 Q/K/V 投影与 head rearrange 之后：

```text
if self.is_selfattn and rope_emb is not None:
    q_scale = self.q_norm.weight.to(dtype=q.dtype, device=q.device)
    k_scale = self.k_norm.weight.to(dtype=k.dtype, device=k.device)
    eps = float(getattr(self.q_norm, "eps", 1e-6))
    q, k = quant_ops.ck.rms_rope_split_half(q, k, rope_emb, q_scale, k_scale, eps)
else:
    q = self.q_norm(q)
    k = self.k_norm(k)

v = self.v_norm(v)
return q, k, v
```

### 3.1 Scale 转换（方案 B）

Anima 使用 Comfy `operations.RMSNorm`（无 Forge `weights_manual_cast` 流）。从 `q_norm.weight` / `k_norm.weight` 取 scale，并转换到 activation 的 dtype/device 后再传入融合调用。

### 3.2 属性名

Comfy `Attention` 使用 **`is_selfattn`**（不是 classic 的 `is_SelfAttn`）。

## 4. 安装规则与控制台消息

| 条件 | 行为 |
|---|---|
| 首次成功安装 | 替换 `Attention.compute_qkv`；打印成功行（并写日志） |
| 已安装 / 已打标记 | 空操作；返回 True |
| 缺少 `rms_rope_split_half` | 保持原版 `compute_qkv`；仅警告一次 |
| 安装过程异常 | 保持原路径；仅打印失败一次 |

**成功行（Forge 控制台可见）：**

```text
[Anima] Installed rms_rope_split_half fuse on comfy.ldm.cosmos.predict2.Attention.compute_qkv (SelfAttn+rope only; CrossAttn unchanged).
```

消息使用 **`print` + logging**（与 FA-2 / `attention_backend_info` 同型），以便出现在 WebUI 控制台，而不仅是某个 logger 命名空间。

时机：Anima UNet 加载时，在 state-dict 键摘要之后、`K-Model Created` 之前打印。

---

## 5. 范围与副作用

### 5.1 预期影响

- Anima DiT SelfAttn 且有 `rope_emb` → 融合内核
- CrossAttn / 无 rope 的 SelfAttn → 原版 `q_norm` / `k_norm`
- `v_norm` 始终为原版
- Attention 后端选择不变（Anima 请用 **Default** 或 **FA-2**；SA2/SA3 对 Anima 画质仍不推荐）

### 5.2 共享类副作用（已文档化）

Install 会替换 `comfy.ldm.cosmos.predict2.Attention` 的**类方法**。进程内一旦加载过 Anima，其他使用同一类的加载器（例如 Cosmos Predict2 MiniTrainDIT）也会看到补丁后的方法。

补丁内已有缓解：

1. 融合分支仅限 **SelfAttn + rope**
2. Install **仅**从 **Anima 加载分支** 调用

## 6. 依赖升级

仓库根目录 `requirements.txt`：

```text
comfy-kitchen>=0.2.21
```

若安装的是旧版 kitchen，Anima 仍可走原路径加载，并打印一次性控制台警告。升级 venv 内包后方可启用融合。

请使用本 fork 的 `venv`（`webui.bat` 激活的那个），不要用无关环境。

## 7. 次要：FA-2 / SA2 / SA3 “kernel ran” 日志

提交 **`eda1d8f`**（`backend/attention_backend_info.py`）：

- 诸如 `[Forge] FA-2 kernel ran ...`（以及 SA2/SA3 对应行）仅在**真实内核返回之后**打印，而不是仅仅因为选中了分发路径。
- 减少切换 Attention UI，或后端已安装但该次采样未真正调用时的误报。

与 Anima 融合正交；作用于全模型共享的 Attention 分发器。
