## IoPaint launcher (`iopaint-cuda.bat`)

Fixes startup reliability when IOPaint runs alongside ComfyUI on the same machine.

### What changed

- **Default port `8081`** — ComfyUI **AiHelper** uses **`8080`**; IOPaint now binds to **`8081`** so the browser does not hit the wrong service (e.g. 404 on `/`).
- **Readiness poll before opening the browser** — PowerShell waits up to **120 seconds** for `http://127.0.0.1:8081/api/v1/server-config` to return **HTTP 200**, then launches the browser. If the server never becomes ready, the batch exits with an error instead of opening a blank or wrong page.
- **Working directory** — `cd /d` to the repo root so `venv\Scripts\python.exe -m iopaint start` runs from the correct path.

### How to use

1. Ensure the WebUI **`venv`** has IOPaint installed (first launch via Forge installs it in `prepare_environment()`).
2. Run **`iopaint-cuda.bat`** from the repo root (or double-click after clone).
3. When you see **"IOPaint is ready. Opening browser..."**, the UI should load at **`http://127.0.0.1:8081/`**.

### Notes

- GPU env vars in the batch (`CUDA_VISIBLE_DEVICES=0`, etc.) are unchanged from prior versions.
- If readiness times out, check that the venv is valid and CUDA is available; open **`http://127.0.0.1:8081/`** manually after the server starts.
