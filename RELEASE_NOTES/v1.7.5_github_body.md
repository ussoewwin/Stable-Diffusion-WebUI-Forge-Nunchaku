## ADetailer (built-in extension)

Face detection **no longer uses InsightFace**. Detection is **YOLO only**.

### What changed

- Removed the hybrid path that ran YOLO first and then used InsightFace to catch missed faces.
- Face models in the ADetailer UI now use `ultralytics_predict` only.
- Removed `hybrid_face_predict` and related exports from the built-in ADetailer extension.

### Notes

- InsightFace-related code may still exist elsewhere in the extension (e.g. standalone InsightFace models, install helpers). **Default face detection for ADetailer no longer depends on InsightFace.**
